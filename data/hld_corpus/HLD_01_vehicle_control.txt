1. System Overview
The Vehicle Control contains the following software components:
Component: VehicleController
Component: DiagnosticManager
Component: CommunicationManager
Component: BrakeController
Component: SensorManager
Component: LoggingManager

2. Interfaces
Interface: VehicleControlInterface
Interface: DiagnosticInterface

3. Signals
Signal: VehicleSpeed
Signal: BrakePressure
Signal: DiagnosticRequest
Signal: DiagnosticResponse
Signal: SensorStatus

4. Component Responsibilities
VehicleController uses interface VehicleControlInterface.
DiagnosticManager uses interface DiagnosticInterface.
CommunicationManager uses interface BrakeStatusInterface.
BrakeController uses interface SensorDataInterface.
SensorManager uses interface LoggingInterface.
LoggingManager uses interface VehicleControlInterface.

5. Communication and Dependencies
VehicleController connects to DiagnosticManager.
DiagnosticManager connects to CommunicationManager.
CommunicationManager connects to BrakeController.
BrakeController connects to SensorManager.
SensorManager connects to LoggingManager.
LoggingManager depends on VehicleController.

6. Functional Flow
VehicleController provides VehicleSpeed to DiagnosticManager.
DiagnosticManager provides BrakePressure to CommunicationManager.
CommunicationManager provides DiagnosticRequest to BrakeController.
